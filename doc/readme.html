Author: Farid Muhammad
Repository: https://github.com/farid5006/PolyVoice

What is PolyVoice?

PolyVoice is a hybrid virtual synthesizer driver and intelligent language router for the NVDA screen reader. It dynamically detects all speech synthesizers installed on your system (such as IBMTTS, SAPI5, Windows OneCore, eSpeak NG, RHVoice, Piper) and seamlessly routes speech to them based on text language, without audio overlap or speech racing.

Key Features

  • Pure Router Architecture: Respects each synthesizer's individual settings (rate, pitch, volume) configured in NVDA. It does not force or override your engine settings.
  • Character-Level Language Detection: Accurately isolates non-Arabic or foreign words embedded in sentences down to the character level.
  • Zero Audio Overlap: Smart queueing with digital stamp tracking prevents speech engines from speaking over each other.

Configuration & Setup

  1. Open NVDA Menu ➔ Preferences ➔ Settings... (or press NVDA + Control + G).
  2. Select PolyVoice from the categories list.
  3. Ensure Enable automatic language switching is checked.
  4. Select a Language from the drop-down menu (e.g. English, French).
  5. Select your preferred Synthesizer Engine for that language.
  6. Click Assign engine to language.
  7. (Optional) Adjust the Delay when switching synthesizers (in milliseconds) to prevent overlap on slow engines (e.g. 250ms for SAPI5).
  8. Repeat for any other languages you wish to customize.
  9. Click OK to save your settings.
  10. Press NVDA + Control + S to open the Synthesizer selection dialog and select PolyVoice.

Useful NVDA Shortcuts

  • NVDA + Control + G — Open NVDA Settings dialog (then select PolyVoice category).
  • NVDA + Control + S — Open NVDA Synthesizer selection dialog (to select PolyVoice).
